# Vision

> **Status:** Draft · **Date:** May 2026

---

## Morsel

Morsel: tiny kitchen, small apps, buffet prices.

A self-hosted platform-as-a-service for non-production applications — demos, experiments, internal tools, etc. It gives developers a Heroku-style experience: push code, get a running app with a URL. It gives operators a low-maintenance system they can run part-time without cloud expertise.

The core promise is that a developer should be able to go from zero to a deployed, HTTPS-accessible application without knowing anything about Kubernetes, cloud infrastructure, DNS, or certificates. The operator should be able to keep the platform running with a few hours of attention per month, without ever touching kubectl or the cloud console.

I am building this to have a way to spend my effort enjoying lots of small bites at bespoke apps, not maintaining infra, and not worrying about costs. I am also keeping the door open for medium-sized, high-trust groups to run apps in their internal infra.
